# Pocket Guestbook
An ESP8266 based web server with some interesting wikipedia articles, games, and a guestbook.

## Requirements
- Download the PlatformIO VSCode extension

- Navigate to the PlatformIO icon in the sidebar 

- General > Upload

- Platform > Upload Filesystem Image

- Open phone, connect to NicePortal

- If you aren't redirected, navigate to niceportal.lan
